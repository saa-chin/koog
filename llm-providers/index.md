# LLM providers

Koog integrates with major LLM providers and supports local models through integration with [Ollama](https://ollama.com/).

- OpenAI
- Anthropic
- Google
- DeepSeek
- OpenRouter
- Bedrock
- Mistral
- Ollama

Note

For more information on using LLMs from these providers to run prompts and create AI agents, refer to [Prompt API](../prompt-api/#choosing-between-llm-clients-and-prompt-executors).
